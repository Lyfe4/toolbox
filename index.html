connect-src 'none'

Every document here is served with a Content-Security-Policy that removes the browser’s ability to make a network request at all. fetch, XMLHttpRequest, WebSocket and sendBeacon are refused in the network stack, below the JavaScript — so nothing on this page can send what you paste anywhere, including code we did not write. Checked in Firefox and WebKit against the built app on every change, rather than asserted.
